# Cyber Toolkit

A Python toolkit for network security tasks, built as part of my Master's in Cybersecurity Engineering and Cybercrime.

The project brings together port scanning, log analysis, encrypted messaging, a password manager with two-factor authentication, and a basic honeypot.

I'm building it module by module on Kali Linux, with a command-line interface, SQLite storage, and CSV/PDF exports.

## Planned features

- TCP port scanning across multiple hosts
- SSH and HTTP log analysis with IP geolocation
- Encrypted client-server messaging
- Password management with asymmetric encryption and 2FA
- Honeypot activity logging
- Controlled UDP and SYN flood demonstrations in an isolated lab
- Security reports and data exports

## Status

Early development. Features will be added and documented as they are completed.

## Usage

Designed for learning and testing on systems I own or have permission to assess.
